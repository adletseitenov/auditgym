# Как начать работать (для команды)

Мы делаем среду для ИИ-аудитора на Genesis Hackathon, трек FinTech. Сдача — 22.11 до 12:00. Жюри ставит 90 из 100 баллов программой, поэтому главное — точное выполнение условий кейса и свои проверки.

## За 10 минут
1. Установи [Claude Code](https://claude.com/claude-code) и git. Нужен Python 3.11 или новее (`python3 --version`).
2. Склонируй репозиторий и открой свою ветку:
   ```bash
   git clone <ссылка на репозиторий> auditgym && cd auditgym
   git checkout -b <gen | env | judge | pack>
   python3 -m auditgym check
   ```
   Последняя команда должна закончиться строкой `CHECK: PASSED`.
3. Запусти `claude` в этой папке. Скиллы, агенты и правила проекта уже лежат в репозитории (`.claude/`, `CLAUDE.md`) и подхватятся сами.
4. Прочитай по порядку: `docs/CONTRACTS.md` (15 минут, обязательно), свою таблицу в `docs/TASKS.md`, при необходимости `docs/SPEC.md`.
5. Вставь в Claude Code свой первый запрос из раздела ниже.

## Как работаем
- **Своя зона — свои файлы.** Список в `docs/TASKS.md`. Нужно что-то в чужой зоне — напиши владельцу.
- **Цикл:** задача → код и тесты → `/verify` → коммит → `git push`. Когда задача готова, поставь `[x]` в `docs/TASKS.md` и напиши в чат.
- **Контракт не меняем молча.** Не подходит формат из `docs/CONTRACTS.md` — сначала чат, потом правка.
- **Скиллы:** `/verify` перед каждым пушем; `/scorecard` — сколько баллов сейчас; `/error-type`, `/fuzz-episodes` (генератор); `/leak-hunt`, `/metamorph` (среда); `/reward-attack` (оценщик); `/jury-readme`, `/pitch`, `/env-pack` (сдача); `/overnight` — оставить Claude работать на ночь.
- **Жёсткие правила кода:** только стандартная библиотека Python; случайность только через `auditgym.rng`; деньги — целые числа, курсы — `Decimal`, без `float`; ничего про эталон не попадает в ответы среды.
- **Если работаешь в ChatGPT или Codex:** правила проекта продублированы в `AGENTS.md`. В обычный чат вставляй `docs/CONTRACTS.md` и свою задачу целиком; код проверяй командой `python3 -m auditgym check`.

## Первый запрос для каждого

**Адлет — генератор (`gen`):**
> Прочитай CLAUDE.md, docs/CONTRACTS.md, docs/SPEC.md (разделы «Модель книг» и «Определения ошибок») и мою таблицу gen в docs/TASKS.md. Сделай задачу G1: auditgym/config.py и auditgym/storage.py с тестами в tests/gen/, проверь на tests/fixtures/tiny. Работай только в файлах зоны gen. После — /verify и коммит. Затем предложи план для G2.

**Алан — среда (`env`):**
> Прочитай CLAUDE.md, docs/CONTRACTS.md (особенно раздел 5), docs/CASE.md разделы 03–04 и мою таблицу env в docs/TASKS.md. Сделай задачу E1: auditgym/evaluator.py, который загружает эпизод из каталога tests/fixtures/tiny и выполняет list_records, get_record, get_document со страницами по 50, курсорами, счётчиком шагов и кодами ошибок из контракта. Тесты — в tests/env/, на unittest. Работай только в файлах зоны env. После — /verify и коммит. Затем сделай E2 (калькулятор).

**Ибрахим — оценщик и решатель (`judge`):**
> Прочитай CLAUDE.md, docs/CONTRACTS.md (разделы 3, 6, 7), docs/CASE.md раздел 05 и мою таблицу judge в docs/TASKS.md. Сделай задачи J1 и J2: auditgym/findings.py (проверка структуры выводов: что даёт награду −1, что проходит) и auditgym/reward.py (точность, полнота, F1 с пустыми случаями и формула награды дословно из кейса). Тесты — таблицей случаев в tests/judge/, на unittest. Работай только в файлах зоны judge. После — /verify и коммит. Затем сделай J3 (matcher и judge) на tests/fixtures/tiny.

**Акжаркын — организаторы, проверка определений, сдача (`pack`):**
> Прочитай docs/CASE.md, раздел «Определения ошибок» в docs/SPEC.md и мою таблицу pack в docs/TASKS.md. Помоги мне с задачей P4: для каждого из четырёх типов ошибок и каждого отвлекающего случая придумай пример с конкретными суммами, датами и валютами и проверь, однозначно ли правило говорит «ошибка» или «не ошибка». Запиши таблицу в docs/DEFINITION-REVIEW.md, спорные случаи выдели отдельно.

Задачи P1–P3 (кабинет, вопросы организаторам, папка на Диске) делаются руками и в первую очередь: от ответов организаторов зависит работа остальных.
