# Результаты базовых политик

Файл целиком пишет `python -m tools.report` (`make report`); руками числа не правим.
Генератор 0.1.0, схема 1, конфигурация 1, Python 3.14.6. Все политики идут через процесс среды в режиме train.

## Наборы

- train (episodes/train): 8 с ошибками, 2 чистых.
- dev (episodes/dev): 8 с ошибками, 2 чистых.
- генерированный набор (200 эпизодов): 150 с ошибками, 50 чистых.
- В плане train/dev 0 из 20 слотов взяли запасной вариант: генератор пока не умеет предпочтительный (`configs/episodes.json`).
- Из пулов генерированного набора пропущено как неподдерживаемые: 0 конфигураций с ошибками и 0 чистых.

Политики: `oracle` знает эталон (только оценщик); `solver_policy` читает все таблицы и запускает решатель; `reconcile` — простая сверка; `random_explorer` — случайные действия с seed 0; `silence` — пустой ответ; `flag_all*` — атака «пометить всё» в трёх вариантах; `heuristic` — демонстрационная эвристика без учёта отвлекающих случаев (не базовая политика и не часть баллов проверки): одинаковые суммы контрагента как дубли, любой неразнесённый остаток как разрыв, документ с датой вне периода и проводкой внутри как отсечка, расхождение с курсом напечатанной даты как курсовая ошибка; частичные оплаты, позиции, пояс компании и переплаты она не различает.

Колонка «Shaped (эксп.): ошибки» — среднее экспериментальной награды с частичным баллом на книгах с ошибками (`auditgym/shaped.py`, формула в `docs/DESIGN.md`). **Она экспериментальная и не входит в награду кейса:** официальный возврат считается только по формуле CASE §05, колонки «Возврат» её не используют. В режиме eval её нет нигде.

## Проверки порядка

- train (episodes/train): oracle ≥ solver_policy > reconcile > flag_all*, flag_all* ≤ -0.8 на книгах с ошибками и < silence на всём наборе — выполняется.
- dev (episodes/dev): oracle ≥ solver_policy > reconcile > flag_all*, flag_all* ≤ -0.8 на книгах с ошибками и < silence на всём наборе — выполняется.
- генерированный набор (200 эпизодов): oracle ≥ solver_policy > reconcile > flag_all*, flag_all* ≤ -0.8 на книгах с ошибками и < silence на всём наборе — выполняется.
- Лучший вариант flag_all минус silence на книгах с ошибками: train +0.064, dev +0.052, generated +0.031. Молчание там на нижней границе −1, поэтому любое случайное попадание атаки чуть выше него; на чистых книгах атака получает −1, молчание +1.
- Режим eval: политика видит награду 0.0 и пустой info, журнал оценщика равен награде train — да.
