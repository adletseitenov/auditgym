# План реализации

Цель — максимум по пяти критериям кейса (`docs/CASE.md` §10). Задачи с владельцами и сроками — `docs/TASKS.md`. Договор между зонами — `docs/CONTRACTS.md`.

## Порядок
1. **Контракты заморожены** (19.11 21:00). До этого — замечания, после — менять только вместе.
2. **Параллельный старт на заглушках.** Все зоны начинают на `tests/fixtures/tiny`: среде не нужен генератор, оценщику не нужна среда.
3. **КТ-1: сквозной проход** на двух типах ошибок (`duplicate_invoice`, `period_cutoff`) через отдельный процесс-оценщик.
4. **КТ-2: четыре типа**, отвлекающие случаи, атаки на награду, решатель равен эталону на 1 000 seed, точный повтор и перестановки.
5. **Сценарии взаимодействия, политики, слепой взломщик.**
6. **Заморозка и упаковка:** эпизоды, траектории, README, записка, видео, презентация.
7. **Сдача** за 3 часа до дедлайна.

## Что от чего зависит
```
CONTRACTS ─┬─ gen: G1 → G2 → G3 → G4 ─┬─ G5 → G6 → G7 → G8
           ├─ env: E1 → E2 → E3 → E4 ─┤   (E4 ждёт G4 и J3)
           ├─ judge: J1 → J2 → J3 ────┘   J5 ждёт G4, J6 ждёт G5
           └─ pack: P1 → P2 → P3, P4 сразу; P5–P8 ждут готовых зон
```
Кто ждёт соседа, не простаивает: пишет тесты своей зоны и проверки в `tools/score.py`.

## Критерий → кто закрывает
| Критерий | Баллы | Зона | Проверки в `tools/score.py` |
|---|---:|---|---|
| Контракт и изоляция | 25 | `env` | 15 |
| Данные и эталон | 25 | `gen` + решатель из `judge` | 10 |
| Надёжность награды | 25 | `judge` | 12 |
| Воспроизводимость и обобщение | 15 | `env` (метаморфизм) + `gen` (поверхность) | 8 |
| Инженерия и объяснение | 10 | `pack` | 5 |

## Правила работы с git
- Ветка на зону; в `main` сливает Адлет после зелёной единой команды. Маленькие коммиты, Conventional Commits, на английском.
- Утром и перед каждой контрольной точкой: `git fetch && git rebase origin/main`.
- Перед пушем: `python -m auditgym check` зелёный. Скилл `/verify` делает это и остальное.
- Ничего не коммитим в чужую зону и в `docs/CONTRACTS.md` без согласования.

## Что режем, если отстаём (по порядку)
1. Обёртка Gymnasium, HTTP-адаптер, экспериментальная награда.
2. Валюты не с двумя знаками; вторая иностранная валюта.
3. Мутационные тесты; фазз 10 000 → 2 000 seed.
4. Часть отвлекающих случаев (оставить не меньше пяти).

**Не режем никогда:** контракт, отдельный процесс-оценщик, однозначность эталона, пять свойств награды, оба сценария взаимодействия, чистые компании, загрузку из файлов, запуск одной командой.

## Критерий отказа
Если к КТ-1 нет сквозного прохода: одна базовая валюта везде, кроме `fx_error`; один сценарий взаимодействия собираем первым (`I2`, он проще), второй — только после КТ-2.
